## 0:55 to 1:35  Search and filter

**Action:** Search for MC-DEMO-002, reset, then select Gelugor under Area and Pedestrian access under Notice type. Open the result.

I can search by a place, notice reference or keyword. Searching for MC-DEMO-002 finds the pedestrian-access notice. Area and notice-type filters can be combined with a keyword. The cards and markers update together. Reset restores all results. Selecting this card shows the work period, potential community impact and access information.

## 1:35 to 2:05  Open an announcement and return

**Action:** Choose Read full announcement, then View impact map on the existing detail page.

Read full announcement opens the existing announcement page using the selected reference. View impact map brings me back to that notice and location. The map reads the original announcement collection, so its text and dates stay consistent with the rest of the website.

## 2:05 to 2:45  Explain the models

**Action:** Briefly show the use case and class diagrams.

The use case diagram shows the public and staff roles across the five agreed functions. Public users can read announcements and explore the map without signing in. Staff sign-in is a planned condition for the dashboard. The class diagram links announcements to construction sites and models feedback with its status history. Submitted, In Progress and Responded are the proposed feedback states. These diagrams describe the overall system design; the later feedback and staff workflows are separate from this map implementation.

## 2:45 to 3:00  Finish

**Action:** Return to the map, select a notice, then use Home in the shared navigation.

On a phone, notice details appear below the map. Users can still see the selected marker. If an online map is unavailable, the schematic keeps the information accessible. That completes my map and model contribution.
