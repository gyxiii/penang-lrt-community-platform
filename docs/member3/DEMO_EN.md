## Before recording

Open the current website using its launcher. The previous ZIP contains outdated scope notes, so use the corrected working copy for preparation. Keep the same browser and site origin throughout the feedback demonstration. Use fictional input only. Prepare the following text for pasting:

- Summary: Unclear temporary walkway signs
- Type of concern: Pedestrian access
- Area: Gelugor
- Location: Sample walkway beside the construction boundary
- Description: The temporary walkway signs are difficult to follow near the sample work area. Please review the pedestrian access arrangement and provide clearer guidance for pedestrians.

An attachment is optional. It can be omitted to keep the recording concise. Never present a sample complaint or response as an actual project case.

## 0:00 to 0:20 Introduction

On screen: homepage, then select Submit Feedback.

“My front-end module covers feedback submission and feedback tracking. These features give residents and local businesses a structured way to record construction-related concerns and follow their progress in MutiaraConnect.”

## 0:20 to 1:30 Submit feedback

On screen: submit the empty form briefly to show validation, then fill the prepared fictional details. Submit once.

“The feedback form asks for a summary, concern category, affected area, location and description. Required-field messages explain what needs to be corrected. Users can also attach a JPG, PNG or WebP image up to two megabytes. The page checks the image type and size before saving. I will submit a sample concern about unclear pedestrian signs near a work area.”

Do not spend time reading every field aloud. If the optional image is demonstrated, show a prepared example and keep the explanation brief.

## 1:30 to 2:00 Reference and receipt

On screen: success receipt. Show the reference, use Copy reference if available, then select Track this feedback.

“The successful submission produces a unique feedback reference. The receipt summarises the concern and area, and provides a direct route to the matching report. Keeping this reference allows the user to return to the report later.”

If clipboard access is unavailable, select the reference and copy it manually. Do not change browser permissions during the recording.

## 2:00 to 3:00 Track progress

On screen: the newly submitted report, refresh once, then select the Responded sample MC-FB-DEMO-003.

“The tracking screen retrieves the report by its reference. This new report is Submitted, and its initial history entry is visible. Refreshing the page retains the record in the same browser. I will now open a separate fictional sample that already contains a response. Its Submitted, In Progress and Responded history shows how the interface presents progress. The latest response is displayed beside the timeline. Invalid and unknown references give a clear explanation.”

Keep the distinction explicit: the new report has not automatically been processed. The responded example is a different sample record.

## 3:00 to 3:30 Reference lookup and recovery

On screen: enter the unknown fictional reference MC-FB-NOTFOUND and submit the lookup. Show the no-match message, then select MC-FB-DEMO-003 again.

“Users can also enter a saved reference directly. If the reference is invalid or cannot be found, the page explains the problem instead of displaying an unrelated report. The sample links provide a quick way to return to a known demonstration case.”

If the group needs a shorter segment, omit this example and move directly to the closing explanation. The full UI catalogue is optional shared material, not a required part of this Member 3 segment.

## 3:30 to 4:00 Scope and close

On screen: tracking page for the Responded sample.

“This Part A version is a front-end simulation. New feedback is saved in the same browser, and no actual complaint is sent to the project team. The module includes the submission form, receipt, reference lookup and status history. The formal administrator page and its connection remain for the administrator module owner to implement.”
